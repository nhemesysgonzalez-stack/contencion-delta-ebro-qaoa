# 🛡️ Optimizador Cuántico de Contención Ambiental (QAOA) — Delta del Ebro

Aplicación web interactiva de Economía Azul basada en **IBM Qiskit (QAOA)** diseñada para apoyar la toma de decisiones en emergencias ambientales y protección de cultivos de acuicultura (mejillón y ostra) en las bahías del Delta del Ebro (Tarragona).

🔗 **Prueba la aplicación en vivo aquí:** https://contencion-delta-ebro-cuantica.streamlit.app/

## 🌊 Impacto y Funcionalidades
* **Optimización Combinatoria (QAOA):** Codifica el valor ecológico, el riesgo por corrientes marinas, el presupuesto limitado de barreras absorbentes y las restricciones logísticas directamente en el Hamiltoniano cuántico.
* **3 Modos Operativos:** Permite trabajar con escenarios predefinidos del Delta del Ebro, editar parámetros manualmente en vivo o subir tablas reales de laboratorio/salvamento en formato **CSV / Excel**.
* **Validación en Hardware Cuántico Real (IBM Quantum):** Preparado para escalar desde simulación matemática exacta hacia pruebas piloto en procesadores cuánticos físicos (QPU).
